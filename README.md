# Don Chelo – Sistema de Punto de Venta

Proyecto de Interacción Humano Computador, Unidad 2, Universidad Mayor.

**Integrantes:** Priscilla Jiménez Vera y René Fredes.

**Objetivo:** Diseñar un sistema de punto de venta para una panadería y minimarket que facilite el registro de productos, el cálculo de pagos y la consulta de inventario.

**Tecnologías:** HTML, CSS, JavaScript y Figma.

**Funcionalidades del prototipo:** búsqueda de productos, ticket de venta, cálculo de vuelto, registro simulado de ventas, validación de stock y panel de administración.

**Ejecución:** abrir el archivo `index.html` en un navegador web.

**Estado:** prototipo académico funcional con datos simulados. No emite boletas tributarias ni almacena las ventas permanentemente.
